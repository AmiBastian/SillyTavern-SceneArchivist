# Scene Archivist 2.1.0

Long character lists can now supply complete relevant bullets to a reply, and archive questions can recover details from verified original messages when saved notes are insufficient. New evidence, reference and troubleshooting controls make it easier to see what was used and recover from a failed helper request.

## What changed

- Optional precise delivery runs after native World Info activation and respects the shared memory allowance. Protected lists, explicit full-detail requests and semantic-only matches stay whole. Memory Trail identifies selected line ranges.
- Ask the archive and supported memory tools can find complete dated excerpts deep inside character lists. Ask can make one bounded follow-up with related wording and verified original messages from the current chat, with evidence and guarded message links.
- Selected helper profiles stay selected after failures. Condensation uses the selected route, request limits and telemetry too.
- Structured memory extraction can retain selection-checked message citations, archive ids and learning notes. Optional memory and condensation audits flag unsupported claims or omissions for review. Failed or paused audits retain their proposals for retry or explicit skip without another extraction.
- Reference selection shows estimated sizes and offers an explicit allowance and complete-entry fitting policy. The default keeps the whole selected reference text.
- Simple, Detailed and Mostly Automatic workflow presets explain their extra requests and review behavior. Forgotten-detail diagnosis and reviewed structural diagnostics help troubleshoot a missing memory.
- Library pages through all results in groups of 100. Search preparation and tokenizer work use bounded caches; identical tokenizer requests are coalesced.
- Fixed the non-empty allocation crash, escaped imported record ids in additional controls, and retained new workflow toggles in exports.

## Update and first use

Use SillyTavern's extension update control, then reload. Back up an active story through **Tools → Maintain → Backups and restore** before updating. Saved books, revisions and unfinished jobs remain supported.

Existing installations keep precise delivery off until explicitly enabled under **Tools → Prompt** or through a workflow preset. Optional audits and AI Recall add requests. Reference fitting can omit complete entries only when explicitly selected; review the estimate and omission notice.

## Validation and limits

Automated behavior, fault recovery, benchmark reproducibility and native SillyTavern 1.19.0 Chromium checks are recorded in the [validation record](2.1.0-VALIDATION.md). Native browser checks use invented stories and scripted model replies.

No model or embedding connection was configured in the release test host. Real-model extraction, audit judgment, free-form answer quality and actual embeddings remain unverified. The optional in-app grounding check makes up to five real requests on your selected connection after a cost notice; it is a constrained connection check, not a quality ranking.

Memory citations are model-cited and selection-checked, not proof that every claim follows from its source. Changed or ambiguous wording does not inherit an old exact-text binding. Native semantic activation is retained; this release does not add an independent semantic index of every event. Other browsers, physical mobile devices and other SillyTavern versions remain unverified. No competitor ranking is claimed.
