# 2.1.0 validation record

Release preparation: 8 November 2026. The integrated core is private development commit `71cb1f061853610fead8b432e055f629c602ddff`, tested before the release metadata, documentation and publishing checks were added.

## Reproducible checks

Local preflight passed all 132 tests, syntax/import checks for all 63 JavaScript files and all 24 benchmark cases. The five added release tests cover publishing scope, exact tag targets, retry idempotence, preservation of existing tags/releases and HTTP failure handling.

- `npm test`: behavior, routing, native activation, evidence handling, fault recovery, audit retry/skip, reference fitting, portable workflows and release-publishing guards.
- `npm run check`: syntax for every JS/mjs file, local imports and matching manifest, version, README and changelog metadata.
- `npm run benchmark -- --check`: all 24 committed foundation, list and source/rewrite cases. Original fixtures, query results and scores remain unchanged; code fingerprints identify the tested implementation.
- Hosted checks exercise Node 22 and 24. Publishing runs those checks again on the exact public main commit before creating a version tag and release.
- The optional core native-host smoke uses SillyTavern 1.19.0 and a separate disposable profile with invented records. It covers original-message lookup and jumps, related wording, 303-record paging, presets, diagnostic privacy preview, native excerpt delivery, line traces, forgotten-detail diagnosis, Memory Trail light/dark/solid/transparent/Fast UI behavior, movement/reset, mobile results and page errors. All nine helper replies are scripted.

New screenshots show that disposable native host, not a production story. Earlier guide images and videos remain labeled examples from the previous workspace where the controls still apply.

The [core checklist](../development/CORE-CANDIDATE.md) records behavior-level evidence and limits. [Local performance samples](../../benchmarks/performance.json) cover lexical search at 1,000 and 10,000 records, not provider latency, browser performance or answer quality.

## Unavailable checks

The host has no configured model credentials or connection profiles. Real extraction omissions, audit judgment, free-form final answers, native embedding results and a common competitor comparison were not measured. No provider requests were made by the release host checks. This limitation is disclosed in the release notes rather than reported as a pass.

Only Chromium desktop and mobile emulation on SillyTavern 1.19.0 are covered. Other host versions, browsers and physical devices remain unverified. The 150-item research roadmap is not marked complete by this release.
