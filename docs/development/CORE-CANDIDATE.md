# Core development candidate

This integrates the earlier foundation, excerpt and original-source work with a larger recall, evidence-review, adoption and scale pass. The baseline is private `develop` commit `825eeb7582acef1f27fea421b38f4b000f7cce32`; this pass was developed on `core-completion` and integrated at `71cb1f061853610fead8b432e055f629c602ddff`. It is included in the [2.1.0 release](../releases/2.1.0.md), whose [validation record](../releases/2.1.0-VALIDATION.md) retains the unavailable real-model checks. The 150-item research roadmap remains a backlog, not a claim that every proposed feature is implemented.

## Implemented capabilities and evidence

| --- | --- | --- |
| Selected model routes | Helpers retain the selected profile; failures do not switch models silently. Condensation now uses the same tracked route, request allowance and telemetry. | Routing and workflow regressions. A custom proxy's actual upstream model is not independently verified. |
| Native reply delivery | Optional precise delivery narrows activated character lists to complete relevant bullets with date context and continuations. Exact, locked, detailed and explicit full-detail records stay whole. | Unit tests and actual native World Info prompt delivery in ST 1.19.0. The setting defaults off; workflow presets can enable it explicitly. |
| Keyword and native semantic activation | All eligible native activations reach the shared allocator, including vector-only records with no lexical match. Such records stay whole when there is no safe matching excerpt. | Structural regressions; no real embedding provider was exercised. This is not an independent semantic index of every bullet. |
| Pre-reply AI Recall | One selected-helper request can choose excerpt ids or supply related queries. Parent ids still go through native World Info activation and the shared cap. | Tests cover indirect wording, scope and nested quiet events. Selection quality still depends on the real model. |
| Question-driven original passages | Ask can search selection-verified saved excerpts, related wording and complete hash-verified original messages in the current chat, with guarded jump links. | Source and workflow tests plus real ST browser flow with scripted replies. Raw passages remain author-only. |

| Troubleshooting | Forgotten-detail diagnosis distinguishes missing saved wording, recorded delivery and recorded exclusions. ## Reproducible checks

Local validation on 8 November 2026 passed 127 tests, syntax and local-import checks for all 61 JavaScript files, and all 24 benchmark cases. Comparing snapshots against the private baseline confirmed that every fixture, query result and score stayed unchanged; only code fingerprints changed. The extended native ST 1.19.0 browser smoke also passed with nine scripted helper responses and no provider calls.

- `npm test`: all behavior and fault-injection tests, including the original three test files.
- `npm run check`: syntax for every JS/mjs file, local import paths and release metadata consistency.
- `npm run benchmark -- --check`: all 24 foundation, list and source/rewrite cases. Existing fixture contents and query-level results are preserved; code fingerprints change intentionally.
- `node scripts/performance.mjs`: local cold and repeated lexical search at 1,000 and 10,000 records. The recorded [sample](../../benchmarks/performance.json) identifies Node and CPU, and excludes browser, saves, embeddings and providers. Timings and heap deltas are samples, not device promises or peak-memory bounds.
- `SA_CORE_SMOKE=1 node scripts/smoke-recall.mjs` or `node scripts/smoke-core.mjs`: the disposable native-host setup described in [VERIFIED-RECALL.md](VERIFIED-RECALL.md), extended with 303 records, preset application, native excerpt injection, traces, diagnosis, diagnostics, themes, movement/reset and grounding-check UI. All nine generation responses are intercepted and scripted.

## Honest validation boundaries

The local test profile has no configured paid provider. Real extraction omissions, unsupported facts, free-form final answers, actual embeddings and fair competitor comparisons are not established by scripted tests. The in-app grounding check provides a concrete bounded check on a configured connection, but five multiple-choice questions cannot establish overall superiority.

Only Chromium desktop/mobile emulation on the local ST 1.19.0 host is claimed here. Physical mobile devices, other browsers and other host versions remain unverified. Arbitrary per-bullet paraphrases cannot acquire exact original-event provenance merely by retaining a character list's receipt. Original sources stay recoverable, while new exact bindings require supported citations.

Optional research items such as fictional calendars, graphs, imports from every competitor, translations, external catalog submission, an independent semantic event store and server-side shared-writer coordination remain in the research backlog. They are not silently marked complete by this candidate.
